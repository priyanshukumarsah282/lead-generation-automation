# Lead Generation Automation

## Objective
This project automates lead generation using Python in Google Colab.

## Features
- Fetches 30 real user leads using a public API
- Extracts name, email, website, and location
- Cleans duplicate and missing values
- Exports data automatically to Excel
- Uses API integration (bonus feature)

## Tools Used
- Python
- Google Colab
- pandas
- requests
- openpyxl

## Output
Final dataset saved as `lead_generation_data.xlsx`.
